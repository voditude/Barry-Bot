Topic summary — what this lecture covers

Week 1 introduces the basic objects of enumerative combinatorics — sets (unordered, no repeats) and vectors/words (ordered, repeats allowed) — and the four counting tools used all semester: addition, multiplication, subtraction, and bijection. It closes by using these to count words over an alphabet under four kinds of restriction, with the birthday problem and pigeonhole principle as running examples.

1 Basic notions — sets and vectors

from the lecture

Sets. A set is a collection of the form $A = \{a_1, \ldots, a_n\}$ where $a_i \neq a_j$ for all $i \neq j$. The number of elements in $A$ is denoted $|A| = n$. The elements could be anything.

Vectors. A vector/tuple is a list of the form $V = (v_1, \ldots, v_n)$. The length is denoted $\ell(V) = n$. Entries can repeat: $v_i = v_j$ for $i \neq j$ is allowed.

Ordering. In a set, order does not matter: $\{a,b,c\}, \{a,c,b\}, \{b,a,c\}, \{b,c,a\}, \{c,a,b\}, \{c,b,a\}$ are the same set. In a vector, order matters: $(a,b) \neq (b,a)$.

intuition

A set behaves like the contents of a bag: {Paris, Rome} and {Rome, Paris} name the same two-city collection, because nothing in the definition tracks order. A vector behaves like a list read top to bottom: (Paris, Rome) and (Rome, Paris) are different, because position $i$ carries information — which city comes first.

This distinction determines which formula applies later in the course. A set of size $k$ chosen from $n$ options is counted with $\binom{n}{k}$, because combinations do not track order. A vector/word of length $k$ built from $n$ options is counted with $n^k$ (repeats allowed) or $n!/(n-k)!$ (no repeats), because these formulas track position. Before applying a counting formula, first decide whether the object being counted is a set or a vector — that decides which formula family applies.

2 Union, intersection, and the addition principle

from the lecture

Intersection. For sets $A, B$: $A \cap B = \{c : c \in A \text{ and } c \in B\}$. When $A \cap B = \emptyset$, $A$ and $B$ are disjoint.

Union. $A \cup B = \{c : c \in A \text{ and/or } c \in B\}$. Example: $A = \{a_1, a_2\}$, $B = \{b_1, b_2, b_3\}$ → $A \cup B = \{a_1, a_2, b_1, b_2, b_3\}$.

Proposition (Addition principle). For $A, B$ disjoint, $$|A \cup B| = |A| + |B|$$ Extends to $n$ pairwise disjoint sets $A^{(1)}, \ldots, A^{(n)}$: $$\left|A^{(1)} \cup \cdots \cup A^{(n)}\right| = \sum_{i=1}^{n} \left|A^{(i)}\right|$$ Week 3 covers inclusion–exclusion, for sets that are not pairwise disjoint.

intuition

The addition principle requires $A$ and $B$ to be disjoint. If they are not, an element in both $A$ and $B$ is counted once toward $|A|$ and once toward $|B|$, so $|A| + |B|$ counts that element twice. This overcount equals $|A \cap B|$, which is exactly the term inclusion–exclusion subtracts in Week 3: $|A \cup B| = |A| + |B| - |A \cap B|$. Before applying the addition principle, check disjointness. If it fails, use the inclusion–exclusion formula instead.

3 Exclusion and the subtraction principle

from the lecture

Exclusion. For sets $A, B$: $A \subset B$ if $A \cap B = A$. Given $A \subset B$, write $B \setminus A = \{b : b \in B \text{ and } b \notin A\}$.

Proposition (Subtraction principle). Fix $A \subset B$. Then $$|B \setminus A| = |B| - |A|$$

derivation

This follows directly from the addition principle in Section 2. $B$ splits into two disjoint pieces: $A$ and $B \setminus A$ — every element of $B$ is in exactly one of the two, by the definition of $B \setminus A$. So by the addition principle, $|B| = |A| + |B \setminus A|$. Rearranging gives $|B \setminus A| = |B| - |A|$.

Use this whenever a set defined by a property $P$ is hard to count directly, but the full set and its complement (not-$P$) are each easy to count: count everything, count the complement, subtract. Section 7 (the digit-1 example) and the password question below both use this pattern.

4 Direct product and the multiplication principle

from the lecture

Direct product. $A \times B = \{(a,b) : a \in A \text{ and } b \in B\}$ — $A \times B$ is a set whose elements are vectors (ordered pairs). Example: $A = \{a_1,a_2\}$, $B = \{b_1,b_2,b_3\}$ → $A \times B = \{(a_1,b_1),(a_1,b_2),(a_1,b_3),(a_2,b_1),(a_2,b_2),(a_2,b_3)\}$.

Proposition (Multiplication principle). $$|A \times B| = |A||B|$$ Extends to $n$ sets: $$\left|A^{(1)} \times \cdots \times A^{(n)}\right| = \prod_{i=1}^{n} \left|A^{(i)}\right|$$

derivation

Fix any $a \in A$. Pairing it with each element of $B$ gives $|B|$ pairs of the form $(a, b)$. There are $|A|$ choices for $a$, and the pairs produced by different values of $a$ are all distinct (they differ in the first coordinate). So the total count is $|A|$ groups of $|B|$ pairs each: $|A| \cdot |B|$.

This requires the choices to be independent — the set of available $b$ values must not depend on which $a$ was picked. Section 8 breaks this assumption: after choosing a letter for position 1, that letter is no longer available for position 2, so the count is not $n \times n$ but $n \times (n-1)$. When you see multiplication used incorrectly, check independence first.

5 Words — definitions and the four question types

from the lecture

Let $A = \{a_1, \ldots, a_n\}$ be a set, called an alphabet. A word over $A$ is a vector $W = (w_1, \ldots, w_m)$ where $w_i \in A$ for all $1 \le i \le m$.

Example: a length-3 word over $\{a,b,\ldots,z\}$ is $W = (c,a,t)$. Example: a length-5 word over $\{0,1\}$ is $W = (0,1,1,0,1)$.

Four categories of word-counting problems are studied: unrestricted words, elementary restrictions, words without repeats, subword avoidance.

intuition

"Word" here means "ordered list built from an alphabet" — it has no connection to English words. A number plate, a sequence of coin flips, and a phone number are all words in this sense: each is an ordered sequence of symbols drawn from a fixed set of options. The rest of the semester follows a fixed procedure: identify which of the four restriction types applies to a given counting problem, then apply the matching formula from that category.

6 Unrestricted words, the assignment problem, and the bijection principle

from the lecture

Proposition. The number of words of length $m$ over an alphabet of size $n$ is $n^m$. Proof: the set of all such words is $\underbrace{A \times \cdots \times A}_{m \text{ times}} = A^m$; by the multiplication principle $|A^m| = |A|^m = n^m$.

Assignment problem (sampling with replacement): "Each person in a group of $m$ people receives one object, from a collection of $n$ possible objects. In how many ways can this be done?" There is a bijection $\Phi$ between assignments and words: $$\Phi : \big(\text{Person } i \leftrightarrow \text{Object } a_i\big) \;\longmapsto\; (a_1, \ldots, a_m)$$

Proposition (Bijection principle). If $\Phi : A \to B$ is both surjective and injective, then $|A| = |B|$. Proof: surjective $\Rightarrow |A| \ge |B|$; injective $\Rightarrow |A| \le |B|$; together, $|A| = |B|$.

intuition

To count set $A$ directly, find a bijection $\Phi: A \to B$ where $B$ is a set you can already count. Then $|A| = |B|$. This works because a bijection pairs every element of $A$ with exactly one element of $B$ and vice versa, so the two sets have the same number of elements regardless of what $A$ and $B$ contain.

The assignment-problem correspondence above is one instance: instead of counting "words" directly, count "ways to assign objects to people" — a different-looking problem with the same count, because $\Phi$ is a bijection between the two sets. Section 8 (permutations) reuses the same method.

7 Words with elementary restrictions

from the lecture — four worked examples

Number plates. Plates of the form letter-letter-letter-number-number-number. $L = \{a,\ldots,z\}$, $N = \{0,\ldots,9\}$. Set of plates $= L\times L\times L\times N\times N\times N$: $$|L|^3|N|^3 = 26^3 \cdot 10^3 = 17{,}576{,}000$$

Even digits only. Non-negative integers $< 10{,}000$ using only even digits. Integers represented as words in $N \times N \times N \times N$. Even-digit subset is $N_{even}^{\,4}$ where $N_{even} = \{0,2,4,6,8\}$: $$|N_{even}|^4 = 5^4 = 625$$

Contains the digit 1. Non-negative integers $< 10{,}000$ containing the digit 1. By the subtraction principle (Section 3): all integers minus those with no 1s. With $\overline{N} = N \setminus \{1\}$ (size 9): $$10^4 - 9^4 = 3{,}439$$

Two dice summing to 8. $D = \{1,\ldots,6\}$, outcome is a word in $D \times D$. Favourable set $S = \{(2,6),(3,5),(4,4),(5,3),(6,2)\}$: $$P = \frac{|S|}{|D \times D|} = \frac{5}{36}$$

pattern across the four examples

Each example applies one of two operations from Section 3 and Section 4 to a word representation: (1) multiply the number of choices at each position, when the choices are independent — plates, even digits; or (2) count everything and subtract the complement, when the restriction is easier to state negatively — digit-1. The dice example computes a probability the same way, as a ratio of two word counts: $|\text{favourable words}| / |\text{all words}|$. No new counting method is used for probability; only the ratio is new.

Practice Class 1, Q3 — a restriction that is neither multiplication nor subtraction

Nine cars are parked in a row: four identical red, five identical blue. How many ways can they be parked so that no two red cars are next to each other?

Generated answer — may be incorrect, verify against course materials

Place the 5 blue cars first. This creates 6 gaps (before the first, between each pair, after the last) into which red cars can go, at most one red car per gap. Choosing 4 of the 6 gaps:

$$\binom{6}{4} = 15$$

This is a distinct technique from the three examples above: place the unrestricted items first, then slot the restricted items into the gaps between them. It is not covered by direct multiplication or subtraction alone.

8 Words without repeats and permutations

from the lecture

Proposition. Length-$m$ words over $A = \{a_1,\ldots,a_n\}$ ($m \le n$), no letter repeated: $$n \times (n-1) \times \cdots \times (n-m+1) = \frac{n!}{(n-m)!}$$ Proof: $n$ choices for the first letter, $(n-1)$ for the second (the first letter is no longer available), and so on, down to $(n-m+1)$ choices for the $m$th letter.

Permutations. When $n = m$, every letter is used exactly once; the words are in bijection with permutations of length $n$. Example ($n=m=3$): words over $\{a_1,a_2,a_3\}$ without repeats ↔ permutations of length 3: $(a_1,a_2,a_3)\leftrightarrow(1,2,3)$, $(a_1,a_3,a_2)\leftrightarrow(1,3,2)$, $(a_2,a_1,a_3)\leftrightarrow(2,1,3)$, $(a_2,a_3,a_1)\leftrightarrow(2,3,1)$, $(a_3,a_1,a_2)\leftrightarrow(3,1,2)$, $(a_3,a_2,a_1)\leftrightarrow(3,2,1)$.

derivation

Section 4's multiplication principle assumed each choice is independent of earlier choices. Here it is not: using a letter in position 1 removes it from the alphabet available for position 2. So the count at position 1 is $n$, at position 2 is $(n-1)$ (one letter already used), at position 3 is $(n-2)$, and so on. Multiplying these position-by-position counts gives $n(n-1)\cdots(n-m+1)$, which equals $n!/(n-m)!$ after cancelling the shared factors of $(n-m)!$.

When $m = n$, this count is the number of permutations of $n$ objects. "Permutation" has this specific technical meaning here: a word using every element of the alphabet exactly once — not a general synonym for "rearrangement."

9 The birthday problem

from the lecture

In a room of $m$ people, what is the probability that at least two share a birthday (leap years ignored)? Via the assignment/word correspondence (Section 6), a room of people is a length-$m$ word $(b_1,\ldots,b_m)$ over $\{1,\ldots,365\}$.

$$\Pr(\text{shared}) = 1 - \frac{365!}{(365-m)! \cdot 365^m} = 1 - \prod_{i=1}^{m} \left(1 + \frac{1-i}{365}\right)$$

why the crossover happens at m = 23, not m ≈ 180

The relevant comparison is not "$m$ people vs. 365 days" but "pairs of people vs. 365 days." A room of $m$ people contains $\binom{m}{2} = m(m-1)/2$ distinct pairs, and each pair independently has some chance of sharing a birthday. At $m = 23$: $$\binom{23}{2} = \frac{23 \times 22}{2} = 253$$ 253 pairs is already comparable in size to 365 possible birthdays, even though $m$ itself (23) is small relative to 365. The number of pairs grows quadratically in $m$ ($\binom{m}{2} \propto m^2$) while the number of days stays fixed at 365 — this is why the probability rises steeply well before $m$ approaches 365.

10 The pigeonhole principle

from the lecture

The birthday analysis assumed $m \le 365$. If $m > 365$, $\Pr(\text{shared}) = 1$, by:

Proposition (Pigeonhole principle). "Suppose each person in a group of $m$ people receives one object, from a collection of $n$ possible objects. If $m > n$, at least two people will receive the same object." Equivalently: "Any length-$m$ word over an alphabet $A$ with $|A| = n$, where $m > n$, has at least one repeated letter."

The birthday formula continues to hold for $m > 365$: the product picks up a factor of $\left(1 + \frac{1-366}{365}\right) = 0$ once $m$ passes 365, so the product (and hence $1 -$ product) correctly evaluates to 1.

first-principles derivation — first appearance of this concept in the course

Claim: if $m$ items are placed into $n$ containers and $m > n$, at least one container holds two or more items.

Proof by contradiction: suppose instead that every container holds at most 1 item. Then the total number of items placed is at most $n$ (one per container, $n$ containers). But $m$ items were placed, and $m > n$. This contradicts $m$ items being placed with at most $n$ total capacity. So the assumption is false: some container holds at least 2 items.

The two quoted statements above are this same argument restated in vocabulary already defined this lecture — "objects into a collection" and "letters in a word," respectively.

11 Subword avoidance

from the lecture

A subword of $W = (w_1,\ldots,w_n)$ is a contiguous run $(w_i,\ldots,w_{i+j-1})$, where $1 \le i \le n$ is the start position and $1 \le j \le n-i+1$ is the length. Example: the length-3 subwords of $W = (s,p,a,r,k)$ are $(s,p,a)$, $(p,a,r)$, $(a,r,k)$.

For words $W, V$ with $\ell(W) \le \ell(V)$, $V$ avoids $W$ if $W$ is not a subword of $V$.

Open question posed in the lecture: fix a word $W$ over alphabet $A$, let $C_W(m) = \#(\text{words of length } m \text{ over } A \text{ that avoid } W)$. Find an explicit formula for $C_W(m)$. The lecture returns to this in Weeks 5 and 6.

note

The question is left open here, not solved, because the general method is introduced in Weeks 5–6. The "no two red cars adjacent" question in Section 7 is a small instance of the same type of question: it counts words that avoid the subword "RR," solved directly because the alphabet size and restriction are small enough not to require the general method yet.
